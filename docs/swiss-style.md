# 스위스 스타일

![](/images/b1450afa-b034-4a49-92e1-fcf270ec60e1.webp)
_요제프 뮐러-브로크만(Josef Müller-Brockmann)이 디자인한 Juni-Festwochen Zürich 포스터 (1957)._

스위스 스타일(Swiss style)은 20세기 중반 국제 타이포그래피 스타일과 바우하우스, 고전적 모더니즘의 영향을 받아 형성된 [[graphic-design]] 경향이다. 스위스 스타일의 기본 원칙에는 미니멀리즘, 그리드 시스템, 비대칭 레이아웃, 산세리프 서체가 있다. 스위스 스타일은 현대 그래픽 디자인의 기초로 여겨지며, 특히 UI 디자인의 많은 요소가 스위스 스타일의 영향을 받아 형성되었다.

1918년 취리히 응용미술학교에서 강의를 시작한 에른스트 켈러(Ernst Keller)는 단순한 기하학적 조형과 강렬한 색상을 사용하며 스위스 스타일의 기본 원칙을 제시했다. 켈러의 제자 중 한 명인 요제프 뮐러-브로크만(Josef Müller-Brockmann)은 모듈형 그리드 시스템을 완성해 스위스 스타일과 현대 [[graphic-design]]의 기초를 만들었다.

스위스 스타일의 토대는 1920년대와 1930년대의 국제 타이포그래피 스타일(International typographic style)에 있다. 스위스 스타일을 국제 타이포그래피 스타일과 동일시하는 경우도 있는데, 스위스 스타일은 국제 타이포그래피 스타일의 연장선에서 스위스의 미술 교육 시스템의 발전과 함께 형성된 독립적인 양식이다. 스위스 스타일은 국제 타이포그래피 스타일의 원칙들을 정교화하게 재구성했다.
