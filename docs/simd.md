# SIMD

SIMD(Single instruction, multiple data)는 하나의 명령어로 여러 개의 데이터를 동시에 처리하는 병렬 하드웨어 연산 방식이다. 예를 들어 일련의 값을 순회할 때, CPU가 한 번에 한 바이트씩 값을 비교하는 대신 한 번의 명령으로 전체 바이트를 한 번에 비교할 수 있다.
