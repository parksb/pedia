# 마수나가

마수나가(MASUNAGA, 増永眼鏡)는 1905년 마수나가 고자에몬이 설립한 안경 제조 회사다. 마수나가는 일본 최초의 안경 회사이자, 세계에서 가장 오래된 하우스브랜드이다. 첫 생산은 마수나가가 오사카의 안경 장인을 후쿠이로 초빙해 시작했고, 이것이 오늘날 후쿠이 안경 산업의 기반이 되었다. 현재 일본산 안경테의 97%는 후쿠이에서 생산된다.

일반적으로 안경은 림, 브릿지, 템플, 도금, 연마 등을 여러 전문 업체가 분업해 제조하는데, 마수나가는 설계부터 부품 제작과 마감까지 모두 자사에서 관리한다.
