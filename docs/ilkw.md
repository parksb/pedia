# 일광전구

![](/images/cd18d622-5ba6-47c8-a07e-730d1168a8d7.webp)
_SNOWMAN15 Portable._

일광전구는 1962년 김망규 회장이 대구에서 창립한 백열전구 제조 기업이자, 조명 브랜드다. 62년간 백열전구를 생산해 온 일광전구는 백열전구의 수요가 낮아짐에 따라 2022년부터 백열전구 생산을 종료하고, 2024년 브랜드명을 ILKW로 변경하며 광원 제조업체에서 조명기구에 중점을 둔 라이프스타일 조명 브랜드로 탈바꿈했다.
